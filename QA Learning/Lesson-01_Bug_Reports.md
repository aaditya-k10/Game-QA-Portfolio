1. What is a Bug Report?
- A communication document that describes the software defect well enough so the next person can understand, reproduce, investigate and fix it.

2. Why do we need Bug Reports?
- A bug report is needed so the developer can understand the defect, investigate it, reproduce it and fix it.

3. When should we create one?
- One should create the bug report to report a defect in the product.

4. When should we NOT create one?
- One should not create the bug report when there are no evidence of that defect.

5. Who reads a Bug Report?
- A bug report is read by:
  .Developer
  .QA Lead
  .Other Tester
  .Project Manager
