# Software Testing Life Cycle (STLC)

## What is STLC?

STLC gives QA a structured process for testing software. It helps ensure requirements are understood, testing is planned, test cases are prepared, execution is organized, and results are documented before release

## Why is STLC important?

STLC is important as it structures a testing of software. Which means it divides the testing of software into steps which are conqured and applied.

## The 6 Phases

Requirement Analysis
        
Test Planning
        
Test Case Development
        
Test Environment Setup
        
Test Execution
        
Test Closure

### Requirement Analysis

This phase tells on what the test are to be performed. it can be software/games.

### Test Planning

This phase is used to plan the testing on software. Which can be done step by step for diiferent features. It is decided by QA lead.

### Test Case Development

In this phase the test cases are established. which means on what feature a qa needs testing.

### Test Environment Setup

This is setup where the test are performed. Tester can test same features on different hardware to ensure the working of that feature.

### Test Execution

It ensures or verifies if the feature is working as intented or not. In this phase a qa will find buds/glitches occuring in software.

### Test Closure

In this phase the qa team ensures the testing is completed and all features are working as intented without any bugs and error.
